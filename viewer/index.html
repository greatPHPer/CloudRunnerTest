CloudRunner Remote Viewer

Receive a live application preview from a CloudRunner host. This page does not install software or run the remote application on your computer.

To use physical keys, click the preview first. The host must separately approve remote control.

Waiting for a host offer.

ICE diagnostics will appear after connection starts.

On Android, tap “Keep screen awake” while this page is open to reduce screen-timeout interruptions. Keep Chrome in the foreground during the test. Video is sent peer-to-peer; some networks may still need a TURN relay.

Connect to a host

Ask the host to create an offer in CloudRunner. Paste that offer below, create an answer, then send the answer text back to the host.

Only exchange connection text with someone you trust. The host offer contains network connection details. Anyone who completes the exchange can view the host's application window. Remote input requires explicit approval from the host AND activation by the viewer. Mouse, keyboard and typed text are sent to the currently selected application only; there is no file transfer or shell access. Never enable control for an untrusted viewer.
