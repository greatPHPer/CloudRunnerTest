CloudRunner Remote Viewer

Receive a live, view-only Windows application preview from a CloudRunner host. This page does not install software or run the remote EXE on your computer.

Waiting for a host offer.

ICE diagnostics will appear after connection starts.

Video is sent peer-to-peer when the network allows it. This prototype uses STUN only; some networks require a TURN relay and may not connect.

Connect to a host

Ask the host to create an offer in CloudRunner. Paste that offer below, create an answer, then send the answer text back to the host.

Only exchange connection text with someone you trust. The host offer contains network connection details. Anyone who completes the exchange can view the host's application window while that session remains active. This prototype has no remote mouse, keyboard, file transfer, or shell access.
